# Contributing

The contributor guide for VinoCSS, and the doorway to the rules.
`README.md` speaks to the people who use the project,
while this page is for anyone who works on it.
It stays short, and it leads to the guidelines.

## Guides

The rules live in [the guide index](./contributing/index.md),
which names the guides a task can start from and the moment you reach for each one.
You do not need to read them all at once;
the index stays short, and each guide links a deeper one when the task reaches it.
Every guide stands on its own, so nothing is lost by reading only what you need.

## AI tools

The guide set keeps growing as the project grows,
and holding all of it in mind may become hard for anyone.
AI tools can help here: they read the same markdown you do,
and their long context lets them keep many guides in view and apply them consistently.
Consider it a suggestion rather than a requirement, though;
every guide is written to be useful on its own,
so the way you prefer to work remains yours to choose.

## Feedback

If a rule feels unclear, unnecessary, or just wrong, please say so.
The guides are meant to help contributors, not to stand in their way,
and they improve when someone points out where they fall short.
