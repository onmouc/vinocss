# Question

How ai tools treat unclear or improvable requests.
Read when a request is ambiguous or a stronger approach may exist.

## Ask

1. Unclear, incomplete, or conflicting request: ask, do not guess.
2. A wrong guess costs work and tokens to undo.
3. Ask before writing code, so the answer shapes the change.
4. Keep questions short, and offer the options you see.
5. Expect a user who may find intent hard to express.

## Suggest

1. Treat the request as a goal, not a fixed solution.
2. Offer a better approach when one exists, with a brief reason.
3. Suggest clearly; leave the decision to the user.
4. Follow the user's choice once it is made.

## Guidelines

1. Check a request against these guides before acting.
2. A request that conflicts with a guide: name the guide and flag it.
3. Recommend updating the guide when the request is the better path.
4. Change the guide and the code together once the user agrees.
